The skill is one small file. Your agent reads it only when you ask for a piece
of SwiftUI: then it searches the {count} components, checks the minimum iOS of
the one it picks and adds the file to your project.

## Pick your agent

## Without installing anything

Every component page has **Copy full prompt**: paste it into any
agent and it adds that component. The [files for agents](/files-for-agents/)
explain what an agent reads.

## Where it goes

- **The skills CLI** puts the skill in the skills folder of each agent you
  pick, for this project or, with `-g`, for every project. `npx skills update`
  updates it.
- **A plugin or an extension** stays with your agent, which updates it with the
  commands in its tab above.
- **A copy by hand** goes in `~/.claude/skills/swiftui-blocks/` for Claude Code,
  or in `~/.agents/skills/swiftui-blocks/` for Codex, Copilot CLI, Cursor and
  Gemini CLI. Download it again to update it.

## Troubleshooting

<details>
<summary>My agent answers from memory</summary>

Skills load when a session starts. Start a new one, then name the catalog:
“With SwiftUI Blocks, add …”.

</details>

<details>
<summary>It picked a component my app cannot run</summary>

The skill compares the minimum iOS of a component with the deployment target of
your project, and tells you before it adds one that needs a newer iOS. Ask for
one that fits: “… that works on iOS 18”.

</details>

## Questions

<details>
<summary>What is a coding agent?</summary>

An assistant that reads and edits your project from a chat, such as Claude
Code, Codex or Cursor. You do not need one: every component page has **Copy
code** and **Download .swift**.

</details>

<details>
<summary>Does it cost anything?</summary>

No. The catalog and the skill are free and MIT licensed. Finding a component
takes your agent a few thousand tokens.

</details>

<details>
<summary>Where does the file go?</summary>

Into your Xcode project, as a new Swift file in your app target. A component
marked Metal brings a second file, which goes in the same target.

</details>
