## Use it with your coding agent

A coding agent, like Claude Code, Codex or Cursor, can find a component for
you and add its file to your project. Start where you are:

| You… | Do this |
|---|---|
| Already found the component | Open its page and press **Copy prompt for your agent** |
| Want your agent to look for it | Copy the prompt below and change its first line |
| Use the catalog often | [Install the skill](/for-ai-agents/#install-the-skill), then just ask: *add a SwiftUI like button* |
| Do not use an agent | Open a component, press **Copy code** and paste it into a new Swift file in Xcode |

<AgentPrompt />

<details>
<summary>What is a coding agent?</summary>

An assistant that reads and edits your project from a chat, such as Claude
Code, Codex or Cursor. You do not need one: every component page has
**Copy code** and **Download .swift**.

</details>

<details>
<summary>Does it cost anything?</summary>

No. The catalog is free and MIT licensed. Your agent works as it always does,
and finding a component takes it a few thousand tokens at most.

</details>

<details>
<summary>Where does the file go?</summary>

Into your Xcode project, as a new Swift file in your app target. A component
marked Metal brings a second file, which goes in the same target.

</details>
