## Give your agent the whole catalog

Install the skill once, then ask in plain words. Your agent searches the {count}
components, checks the one it picks against your deployment target and adds
one Swift file to your project.

```sh title="Recommended"
npx skills add magnoscg/swiftui-blocks-skill
```

It works with Claude Code, Codex, Cursor, Gemini CLI and other agents that
read skills.

## Or install it the way your agent does

<Tabs>
  <TabItem label="Claude Code">
    ```sh
    claude plugin marketplace add magnoscg/swiftui-blocks-skill
    claude plugin install swiftui-blocks@swiftuiblocks
    ```
  </TabItem>
  <TabItem label="By hand">
    ```sh title="Claude Code"
    mkdir -p ~/.claude/skills/swiftui-blocks && curl -fsS -o ~/.claude/skills/swiftui-blocks/SKILL.md https://raw.githubusercontent.com/magnoscg/swiftui-blocks-skill/HEAD/skills/swiftui-blocks/SKILL.md
    ```
    ```sh title="Codex, Cursor and Gemini CLI"
    mkdir -p ~/.agents/skills/swiftui-blocks && curl -fsS -o ~/.agents/skills/swiftui-blocks/SKILL.md https://raw.githubusercontent.com/magnoscg/swiftui-blocks-skill/HEAD/skills/swiftui-blocks/SKILL.md
    ```
  </TabItem>
</Tabs>
