SwiftUI Blocks is a catalog of {count} copy-paste SwiftUI components,
animations and transitions for iOS 18 through iOS 27. It is not a package:
each component is one Swift file that you add to your project, and two when it
draws with a Metal shader. From then on it is your code, with no version to
track.

## One file, always built the same way

Every file is made of the same parts, in the same order: the license, the
documentation, the component, its demo and its preview. Once you know one, you
know where to look in any of them. [Anatomy of a file](/anatomy/) goes through
each part.

## Built into every component

<div class="built-in">

- **Reduce Motion and Dynamic Type**, and a label on anything that is not text.
- **Right-to-left** layouts, gestures included.
- **A 44-point target** on anything you tap.
- **Either isolation**: it compiles with or without the main actor as the
  default.
- **Localizable text**: what you pass to show or read aloud lands in your
  String Catalog.
- **No deprecated APIs**: warnings are errors where the catalog is built.

</div>
